# AI Author
### An AI-Powered Story and Poetry Generation Project

AI Author is a machine learning and Natural Language Processing (NLP) project developed to explore the use of language models for creative writing. The project combines text generation with genre and writing-form classification to experiment with AI-assisted storytelling and poetry.

Developed as a final year project, it explores how pretrained language models can be used to generate creative text and support different aspects of the writing process.

## Features

- **Creative Text Generation:** Generate stories and poems using language-generation models.
- **Genre Classification:** Explore the classification of text into different literary genres.
- **Writing-Form Classification:** Experiment with identifying or classifying different forms of writing.
- **NLP-Based Processing:** Apply natural language processing techniques to work with textual data.
- **Model Experimentation:** Explore pretrained transformer models for text generation and classification.

## Technologies Used

- **Python** — Core programming language.
- **Jupyter Notebook** — Interactive development and experimentation.
- **Natural Language Processing (NLP)** — Text processing and language-related tasks.
- **Hugging Face Transformers** — Working with transformer-based language models.
- **GPT-2 / GPT-Neo / T5 / BERT** — Models and architectures explored across the project.
- **Simple Transformers** — A framework for experimenting with transformer-based NLP tasks.
- **Pandas** — Working with structured datasets.

*The models and libraries used may vary by notebook and task.*

## Project Objectives

The project explores the intersection of artificial intelligence, machine learning, and creative writing, with a focus on:

- Understanding transformer-based language models.
- Experimenting with AI-generated stories and poetry.
- Exploring text classification using NLP techniques.
- Working with datasets and pretrained models in Python.
- Understanding practical applications of machine learning in language-related tasks.

## Scope and Limitations

AI Author is an experimental learning project exploring AI-assisted creative writing and text classification. Its outputs depend on the models, datasets, and configurations used.

Generated text may contain inconsistencies or inaccuracies, and classification results may vary depending on the quality and characteristics of the input data. The project should be viewed as an exploration of NLP techniques rather than a production-ready writing platform.
